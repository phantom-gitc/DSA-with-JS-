# Day 4: DSA - Loops Basics

Fundamental loop practice questions in JavaScript (for loops, math logic, series, factors, and ranges).

---

## 📌 Questions List

| # | Topic / Question | Description |
| :---: | :--- | :--- |
| **Q1** | **Sum of N Numbers** | Find the sum of first $N$ natural numbers ($1 + 2 + \dots + N$). |
| **Q2** | **Factorial of a Number** | Compute $N! = 1 \times 2 \times \dots \times N$. |
| **Q3** | **Sum of Even & Odd Numbers** | Compute sum of all even and odd numbers separately in range $1$ to $N$. |
| **Q4** | **Find Factors of a Number** | Find and print all divisors of a given number $N$. |
| **Q5** | **Prime Number Check** | Check whether a number is prime (basic and $\mathcal{O}(\sqrt{n})$ approaches). |
| **Q6** | **Multiplication Table** | Print the multiplication table of a number from $1$ to $10$. |
| **Q7** | **Fibonacci Series up to N terms** | Generate the Fibonacci sequence ($0, 1, 1, 2, 3, 5, 8, \dots$). |
| **Q8** | **Calculate Power ($a^b$)** | Compute $a^b$ using a loop without using `Math.pow` or `**`. |
| **Q9** | **Perfect Number Check** | Check if sum of proper divisors of $N$ equals $N$ (e.g. $6, 28$). |
| **Q10** | **GCD / HCF of Two Numbers** | Find the Greatest Common Divisor of two integers using loops. |
| **Q11** | **Print Primes in Range (1 to N)** | Print all prime numbers from $1$ up to $N$. |

---

## 🚀 How to Run

1. Open `index.html` in your browser.
2. Uncomment the question you want to practice in `script.js`.
3. Open the Developer Console (`F12`) to enter input and view outputs.
