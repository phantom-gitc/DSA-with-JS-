# Day 11: String Practice Questions (Easy to Medium)

25 common string interview questions written in clean, practical JavaScript without complex DSA structures.

---

## 📌 Questions List

### Easy (Q1 - Q10)

| # | Question | Function Name |
| :---: | :--- | :--- |
| **Q1** | Reverse a string | `reverseString(str)` |
| **Q2** | Check if string is palindrome | `isPalindrome(str)` |
| **Q3** | Count vowels and consonants | `countVowelsAndConsonants(str)` |
| **Q4** | Capitalize first letter of each word | `capitalizeWords(str)` |
| **Q5** | Find longest word in a sentence | `findLongestWord(sentence)` |
| **Q6** | Remove duplicate characters | `removeDuplicates(str)` |
| **Q7** | Count occurrences of a character | `countChar(str, target)` |
| **Q8** | Truncate string with ellipsis | `truncate(str, limit)` |
| **Q9** | Check if string has only digits | `isOnlyDigits(str)` |
| **Q10** | Mask sensitive data (except last 4) | `maskString(str)` |

---

### Medium (Q11 - Q25)

| # | Question | Function Name |
| :---: | :--- | :--- |
| **Q11** | Reverse words in a sentence | `reverseWords(sentence)` |
| **Q12** | Check if two strings are anagrams | `isAnagram(str1, str2)` |
| **Q13** | Count frequency of each character | `charFrequency(str)` |
| **Q14** | Find first non-repeating character | `firstUniqueChar(str)` |
| **Q15** | String compression (Run-length) | `compress(str)` |
| **Q16** | Convert string to camelCase | `toCamelCase(str)` |
| **Q17** | Check if string is rotation of another | `isRotation(s1, s2)` |
| **Q18** | Custom trim function | `customTrim(str)` |
| **Q19** | Find all substrings of a string | `getSubstrings(str)` |
| **Q20** | Basic email validation | `isValidEmail(email)` |
| **Q21** | Check if string is a pangram | `isPangram(str)` |
| **Q22** | Longest common prefix among strings | `longestCommonPrefix(strs)` |
| **Q23** | Find most frequent character | `maxOccurringChar(str)` |
| **Q24** | Check if string is a subsequence | `isSubsequence(str1, str2)` |
| **Q25** | Check balanced parentheses/brackets | `isValidParentheses(str)` |
